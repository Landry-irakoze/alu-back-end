# alu-back-end

Python scripts in `api/` that gather data from the JSONPlaceholder REST API
(https://jsonplaceholder.typicode.com) and export it.

| File | Description |
|------|-------------|
| `api/0-gather_data_from_an_API.py` | Prints an employee's TODO list progress |
| `api/1-export_to_CSV.py` | Exports an employee's tasks to `USER_ID.csv` |
| `api/2-export_to_JSON.py` | Exports an employee's tasks to `USER_ID.json` |
| `api/3-dictionary_of_list_of_dictionaries.py` | Exports all employees' tasks to `todo_all_employees.json` |
